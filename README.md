# MidiKeyPlayer（MIDI 按键播放器）

导入 MIDI。程序把音符转换成键盘与鼠标按键输出，发送到前台窗口。
内置谱面编辑器。你可以先改谱，再播放。

- 系统：Windows 10 / 11（64 位）
- 单文件 exe。不需要安装 .NET
- 界面语言：中文

> ⚠️ 虚拟输入可能违反第三方软件的使用规则，有账号封禁风险。请只在练习、测试或单机场景使用。后果由使用者承担。

## 下载

1. 打开右侧 **Releases**。
2. 下载 `MidiKeyPlayer-win-x64.zip`。
3. 解压。双击 `MidiKeyPlayer.exe`。
4. 系统弹出 UAC，选「是」。
5. 如果弹出 SmartScreen「未知发布者」，选「更多信息」，再选「仍要运行」。
6. 杀毒软件可能误报「模拟按键」。请把它加入白名单。

## 使用

1. 点「打开 MIDI 文件…」。支持 `.mid`、`.midi`、`.kar`、`.rmi`。
2. 在左侧点一行，作为主旋律。绿点是程序推荐的行。打击乐轨也可以选：有的目标乐器自带鼓组。想一起出声，就在左侧勾多个声部。
3. 需要改谱时，在卷帘上直接改。做法见下。
4. 调速度、移调、倒计时。
5. 点「▶ 播放」，或按 **F6**。
6. 在倒计时结束前切到目标程序。

播放中，你可以拖卷帘或进度条跳转。也可以实时改速度和移调。暂停时可以直接打开另一首换歌。

## 卷帘编辑

卷帘画出整首旋律。上方是时间标尺，按文件的拍号与速度画小节线。左侧是琴键栏。

| 操作 | 作用 |
|---|---|
| 标尺点 / 拖 | 定位播放位置 |
| 点左侧琴键 | 选中该音高的全部音符。按住拖动可连选多个音高 |
| 拖音符中部 | 移动。多选时整组一起动。左右改时间，上下改音高 |
| 拖音符任一端 | 改长度。左端改头，右端改尾。音高不变 |
| 空白处拖 | 框选多个音符 |
| 空白处单击 | 定位，并清空选择 |
| 双击空白 | 加一个音。按住继续拖可一次定好长度 |
| 右键 | 删音。按住拖动可连续擦除 |
| Delete | 删除选中的音 |
| Ctrl+A / Esc | 全选 / 清空选择 |
| 方向键 | 微调。左右按吸附步长，上下按半音。按住 Shift 加速 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做。保留当前缩放位置 |
| 滚轮 | 以光标为锚点缩放 |
| Shift+滚轮 | 左右平移 |
| 中键拖动 | 左右平移 |
| 缩小 / 放大 / 全曲 | 工具栏按钮。右边显示当前缩放百分比 |
| 帮助 | 展开 / 收起右侧的操作说明 |

**颜色。** 每条声轨一个唯一颜色。左侧列表的文字颜色与卷帘里的音符颜色一致。没参与演奏的声轨用灰（打击乐轨稍深一点）。超出音域的音显示为灰色。

**吸附。** 勾选「吸附 0.1s」后，拖动与加音按 0.1 秒对齐。吸附的是音符的头或尾，不是光标。

**改动只存在内存里。** 要留档，点「导出 MIDI…」。程序写出一个标准 MIDI 文件。

**换轨会丢改动。** 切换主旋律轨，或改合奏勾选，程序会丢弃手动改动。日志会写明。想保住改动，先导出 MIDI。

## 试听

点「试听」按钮，用 Windows 自带的 MIDI 合成器播放当前谱面。再点一下停止。

- 它和演奏完全分开：不发送按键，不走倒计时，不会最小化窗口。
- 播放中随时可以拖进度条或卷帘定位。松手就从新位置接着放。
- 不需要安装任何音频软件。设备不可用时按钮会自动变灰，日志里写明原因。

## 选项

- **合奏**。在左侧勾选多个声部一起演奏。编号 1 最优先。乐器一次只发一个音，冲突时先演奏编号小的。
- **保留和弦**。默认勾选。勾选时演奏 MIDI 里的全部音。取消后只演奏一条单音旋律，适合一次只能发一个音的乐器。抽单音用平滑 skyline：每个时刻取最高音，带滞回与最大跳变限制。
- **去除开头空拍**。默认开。剪掉开头的休止，让旋律从第 0 秒开始。卷帘左下角会标出剪掉多少秒。
- **输入兼容**。三档：稳健、标准、极限。目标程序按帧读按键。修饰键与音键的间隔小于一帧就会漏音。掉帧的机器选「稳健」。
- **播放后自动最小化窗口**。默认开。
- **导出按键表**。导出 G HUB 脚本（.lua），或通用 CSV。内容跟随当前键位方案，与实际演奏一致。

## MIDI 设备实时演奏

接上 MIDI 键盘或打击垫，按键直接发送到目标程序。不用先做谱。

1. 在选项区勾「MIDI 设备实时演奏」。
2. 在「设备」里选你的设备。点「刷新」重新扫描（支持热插拔）。
3. 切到目标程序，开始弹。

| 设置 | 作用 |
|---|---|
| 基准八度 | 设备上哪个八度是中音 do。默认 C4 |
| 自动贴合音域 | 默认开。按最近弹过的音自动挑基准八度，跨几个八度弹也不会哑 |
| 力度下限 | 默认 1（不过滤）。设备有抖动或触后噪声时往上加 |

**音高怎么对。**

- 基准八度的 do re mi fa sol la si → `Z X C V B N M`。
- 高一个八度：按住鼠标**右键**。低一个八度：按住**左键**。升半音：按住**中键**。
- 最高只到高高音 `#do`。超出音域的音不发声，日志里写明。
- 乐器一次只发一个音。同时按住多个键时，后来的音优先，前一个音被换掉。

「设备实时演奏」和「文件播放」互不影响。播放期间设备照样能弹，但两路输入会同时生效，
想干净一点就在播放时先取消勾选。状态文字实时显示最近一个音映射成了什么。
停止时日志给出统计：收到多少音、多少超出音域、多少被后来的音顶掉。

设置自动记忆。位置是 `%LOCALAPPDATA%\MidiKeyPlayer\settings.json`。日志在同一目录，文件名是 `play.log`。

## 热键

程序用系统低层键盘钩子。热键在目标程序中直接生效。

| 键 | 动作 |
|---|---|
| **F6** | 空闲 = 开始。播放中 = 暂停。暂停中 = 继续。倒计时中 = 取消 |
| **F5** | 后退 5 秒 |
| **F7** | 前进 5 秒 |

三个键都能改，也能关掉。在界面的「控制热键」「后退热键」「前进热键」里改。

**注意**：播放中跳转可能让目标程序侧卡音。遇到卡音，按「停止」，再重新播放。最稳的用法是播放前用卷帘或进度条定位。

## 注意

1. 目标程序用**窗口化**或**无边框窗口化**。全屏独占收不到模拟按键。
2. 播放开始前，点一下目标窗口。目标程序必须在前台。
3. 输入法切到**英文**。中文输入法会截走按键。
4. 目标窗口内**原地不动**。按住 `W`、`A`、`S`、`D` 时，键盘矩阵会吞掉部分音键。这是键盘硬件限制，软件无法修复。只有全键无冲（NKRO）键盘可以避免。
5. 程序强制以管理员启动。目标程序以管理员运行时，本程序也必须是管理员。否则 Windows 拦截按键。
6. 鼠标或键盘失控时，狂按 **F6**。

## 键位方案

键位、音域与半音处理全部由方案文件决定，不写死在程序里。程序内置 4 套方案，名字按「键数 / 排数 / 能弹几个八度」命名。

| 方案 | 键位 | 功能键 | 音域 |
|---|---|---|---|
| 8 键 1 排 3 个八度（默认） | `Z X C V B N M ,` = do..高音 do | 左键降八度、右键升八度、中键升半音 | 48..85 |
| 7 键 1 排 1 个八度 | `Z X C V B N M` = do..si | 无 | 60..71 |
| 15 键 3 排 2 个八度 | `Q W E R T` / `A S D F G` / `Z X C V B` | 无 | 60..79 |
| 23 键 3 排 3 个八度 | `Q W E R T Y U I` / `A S D F G H J K` / `Z X C V B N M` | 无 | 60..95 |

默认方案的旧行为：`Z X C V B N M` 是中音 do re mi fa sol la si。按住鼠标**左键**整排降一个八度，按住**右键**整排升一个八度，按住**中键**升半音。

**改键位。** 点主界面的「键位设置…」按钮，打开独立的「键位设置」窗口。窗口分四块：

| 区块 | 作用 |
|---|---|
| 方案 | 选方案、导入、导出、另存为、重命名、删除、恢复默认 |
| 按键绑定 | 横排的键帽方块：左上是音名，右下是按键名。点上半改音高，点下半改键，右上 `✕` 解绑 |
| 功能键 | 升高八度、降低八度、升半音，各自绑一个键 |
| 半音怎么处理 | 没有半音输入时，缺的半音是跳过、用高半音顶、还是用低半音顶 |

**等待按键。** 点按键方块后它变成「按一个键…」，按一下键盘或鼠标就绑上。按 Esc 取消。`PageUp`、鼠标键这类手按不到的，点旁边的「选键名」从列表里选。单独按一下 `Shift`、`Ctrl`、`Alt` 再松开，也能把它们绑成功能键。

**哪些音还没绑。** 窗口底部常驻一行统计，例如「绑了 8 条。能弹 C3 到 C#6，其中 30 个音还没有绑键。」

**音域由键位决定。** 不填数字。键能到哪，就能弹到哪：三个八度的键就谈三个八度。超出范围的音不弹。

**半音处理。** 「跳过这个音」= 缺的半音不弹。「用高半音代替」= 当它上面那个音弹。「用低半音代替」= 当它下面那个音弹。

**方案文件。** 内置 4 套方案不能改。想改就先「另存为」一份。自定义方案在 `%LOCALAPPDATA%\MidiKeyPlayer\schemes\` 下，重启后仍在列表里。「导入方案…」「导出方案…」走单个 JSON 文件，方便互相分享。

**每个方案独立记忆。** 速度、移调、输入兼容档按键位方案名分别保存。

**与设备实时演奏的关系。** MIDI 设备输入的基准八度在「MIDI 设备实时演奏」区单独设置。默认方案的键位与上文一致。

## 常见问题

**目标程序里没反应，但在记事本能打字？**

按顺序检查四项。

1. 先点一下目标窗口。
2. 目标程序改成无边框窗口化。
3. 目标程序和本程序都用管理员。
4. 输入法切英文。

**站着不动不漏音，一走位就漏音？**

这是键盘硬件的幽灵按键问题，不是软件问题。见上面「注意」第 4 条。

**偶尔缺音？**

看日志区里播放结束时的「时序诊断」。

- 修饰键提前量不足：把「输入兼容」改成「稳健」。
- 同键重触发偏多：把速度降回 100%。
- 时值被压到下限的音数不是 0：这首谱挤得比该档位允许的最快速度还快。换「稳健」档，或降速。

**MIDI 设备没反应？**

按顺序检查四项。

1. 设备在其它软件里被占用了就先关掉它（MIDI 输入通常只能被一个程序打开）。
2. 点「刷新」，确认设备出现在下拉框里。
3. 状态文字要显示「实时演奏中」。显示「启动中…」不动就是打开失败，日志里有原因。
4. 弹的音在音域外。看状态文字：显示「超出音域」就调「基准八度」，或勾上「自动贴合音域」。

**点窗口的 × 会怎样？**

彻底退出。程序停止播放，松开所有按键，注销热键。只想暂时离开目标窗口，就最小化窗口。托盘菜单可以控制开始、暂停、停止和退出。

## 自动更新

启动时的更新检查**默认关闭**。原因：当前发布在私有库，不带凭据的检查会返回 404。

源码在 `MidiKeyPlayer/Engine/AutoUpdate.cs`。仓库转为公开后，把 `Enabled` 改成 `true` 即可。

## 设置迁移

首次启动时，如果新目录没有设置文件，程序会尝试读旧目录 `%LOCALAPPDATA%\HarpAutoPlayer`，
把速度、移调、热键与 MIDI 设备设置迁移过来。迁移失败只写日志，不打断启动。

## 技术说明

- 界面：Avalonia（.NET 8）。MIDI 解析与设备接入：DryWetMidi。
- 输入：Windows SendInput，扫描码模式。全局热键：WH_KEYBOARD_LL。
- 试听：Windows 自带的 winmm MIDI 输出。没有第三方音频库。
- 时序按物理帧给余量。修饰键提前至少 1 帧。每个音至少按住一帧多一点。同键重触发至少 1 帧。最小间隔用物理毫秒，不随播放速度压缩。
- 音符之间用「槽位」排开：与前音重叠的音顺延到前音之后，不靠缩短前音让位。这样不会产生零时长按键。
- 卷帘坐标换算只有一套。渲染与命中共用，两个方向对称。
